# AmiNews新闻聚合与智能摘要平台 - 开发文档

## 项目概述

**项目名称：** AmiNews新闻聚合与智能摘要平台  
**项目类型：** Web应用程序  
**技术栈：** Vue 3 + TypeScript + SpringBoot + MySQL + Redis + Elasticsearch  
**开发周期：** 2025年6月23日 - 2025年7月8日（2周）  
**项目经理：** 吉尔五沙  
**开发模式：** 前后端分离开发

## 一、系统项目计划

### 阶段一：需求分析和设计（第一周前期：6月23-25日）

#### 1. 确定项目目标和范围
- **项目目标：** 开发一个现代化的新闻聚合与智能摘要平台，为用户提供个性化的新闻阅读体验
- **主要功能和特性：**
  - 用户认证系统（登录/注册）
  - 新闻内容聚合和展示
  - RSS源管理和自动抓取
  - 个性化标签管理系统
  - 稍后再读功能
  - 订阅源管理
  - 智能摘要功能（AI驱动）
  - 新闻问答系统（RAG架构）
  - 热词统计和分析
  - 向量检索和语义搜索
  - 跨平台响应式设计

- **目标用户：** 需要高效获取信息的用户，特别是武汉大学师生群体
- **使用场景：** 
  - 移动端新闻浏览和管理
  - 桌面端深度阅读
  - 跨设备数据同步

#### 2. 进行需求分析
- **核心功能需求：**
  - 用户管理：注册、登录、个人信息管理、JWT认证
  - 内容聚合：RSS源管理、新闻抓取、内容展示、自动更新
  - 个性化管理：标签系统、稍后再读、个人收藏、文件夹管理
  - 智能功能：AI摘要生成、新闻问答、向量检索、热词分析
  - 数据管理：MySQL数据持久化、Redis缓存、Elasticsearch全文检索
  
- **技术要求：**
  - 前端：Vue 3 + TypeScript开发
  - 状态管理：Pinia
  - 构建工具：Vite
  - 样式：响应式CSS设计
  - API通信：Axios + 拦截器
  - 后端：SpringBoot 3 + Java 17
  - 数据库：MySQL + MyBatis-Plus
  - 缓存：Redis
  - 搜索：Elasticsearch
  - AI集成：LangChain4j + OpenAI API

## 二、技术架构详细说明

### 前端技术栈
- **Vue 3：** 采用Composition API，提供更好的TypeScript支持
- **TypeScript：** 类型安全，提高代码质量和维护性
- **Vite：** 快速构建工具，支持热更新
- **Pinia：** 现代状态管理库，替代Vuex
- **Axios：** HTTP客户端，统一API请求处理

### 后端技术栈
- **SpringBoot 3：** 现代化Java企业级开发框架，基于Java 17
- **MySQL 8.0：** 主数据库，支持JSON字段和改进的索引性能
- **MyBatis-Plus：** 增强版MyBatis，简化CRUD操作，支持代码生成
- **Redis 7.0：** 内存数据库，用于缓存和会话存储
- **Elasticsearch 8.8：** 搜索引擎，支持全文检索和向量搜索
- **JWT：** 无状态用户认证
- **LangChain4j：** Java版LangChain，AI应用开发框架
- **Rome Tools：** RSS/Atom解析库
- **HanLP：** 中文自然语言处理
- **Docker：** 容器化部署

### 数据库设计
```sql
-- 核心数据表设计
用户表 (user)：用户基本信息、认证数据
频道表 (channel)：RSS源信息、更新状态
新闻表 (item)：新闻内容、AI摘要、发布时间
标签表 (tag)：用户自定义标签
新闻标签关联表 (item_tag)：多对多关系
稍后再读表 (read_later)：用户收藏功能
订阅关系表 (subscribe)：用户订阅的频道
文件夹表 (folder)：频道分组管理
热词表 (hot_word)：热词统计数据
问答记录表 (qa_record)：AI问答历史记录

-- 索引设计
- 用户邮箱唯一索引
- 新闻标题和内容全文索引
- 发布时间降序索引
- 用户ID + 创建时间复合索引
```

### API接口设计
```
RESTful API 设计规范

用户模块：
- POST /api/user/register     # 用户注册
- POST /api/user/login        # 用户登录
- GET  /api/user/profile      # 获取用户信息
- PUT  /api/user/profile      # 更新用户信息

新闻模块：
- GET  /api/items             # 获取新闻列表
- GET  /api/items/{id}        # 获取新闻详情
- GET  /api/items/search      # 搜索新闻
- POST /api/items/{id}/summary # 生成AI摘要

标签模块：
- GET  /api/tags              # 获取用户标签
- POST /api/tags              # 创建标签
- PUT  /api/tags/{id}         # 更新标签
- DELETE /api/tags/{id}       # 删除标签
- POST /api/items/{id}/tags   # 为新闻添加标签

频道模块：
- GET  /api/channels          # 获取频道列表
- POST /api/channels          # 添加新频道
- PUT  /api/channels/{id}     # 更新频道
- DELETE /api/channels/{id}   # 删除频道
- POST /api/channels/{id}/subscribe # 订阅频道
```
